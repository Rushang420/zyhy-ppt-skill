**迭代原则**

- 一次反馈只改一类问题，改完立刻复验；不要“顺便”改别的页。
- 用户说“回到 vN”，直接基于 `_vN` 新开分支，不在最新版上逆向删。
- 连续两轮同一问题没解决，停下来问“你要的是 A 还是 B”，不要继续猜。
- 结构性反馈（部分数、视频归属）优先于视觉反馈；结构错了先改结构。

## 二、逐页审阅流程（每轮必做）

### 2.1 先看整体，再看单页

1. **30% 缩略图**：全页拼成 contact sheet，检查节奏——是否连续多页同版式、是否有过暗/过空的页。
2. **100% 单页**：逐页看标题、结论句、正文、页脚、logo、页码、图片裁切。
3. **第一眼测试**：每页停留 2 秒，能否说出“这页讲什么”；说不出就重做结论句。
4. **眯眼测试**：眯眼看页面，第一眼落在哪；如果落在边框/色块而不是结论，改版式。
5. **投影测试**：把页面缩到 50%，模拟后排观看；最小字号/灰字是否还能读。

### 2.2 四个专项检查

**A. 结构一致性**

- [ ] 目录条目数 = 章节扉页数 = 讲话稿一级标题数
- [ ] 没有子点被提成“部分”
- [ ] 开篇页不是第二个目录
- [ ] 页码连续，增删页后已重排

**B. 内容保真**

- [ ] 每页结论句能在原稿找到（原句或截取）
- [ ] 上屏文字无新增词/数据/事例
- [ ] 核心提法、公司名、项目名、数字单位逐字一致
- [ ] 原稿没有的提法（哪怕公报有）没有上屏

**C. 视觉与节奏**

- [ ] 无“框加框”；无九宫格色块堆叠
- [ ] 同一数字全篇只做一次重点
- [ ] 过渡页与内容页明度一致
- [ ] 图片不重复、不拉伸、不压字
- [ ] logo 位置统一；页脚不被裁

**D. 媒体与交付**

- [ ] 视频归属章节正确；首帧无闪错数字
- [ ] 视频单独成页、能播放、有声音
- [ ] Morph 在 PowerPoint 2019+/365 实测
- [ ] PDF/无视频版已生成
- [ ] 字体替代风险已提示

## 三、逐字回查脚本（python-pptx）

### 3.1 抽取全部上屏文字

```python
from pptx import Presentation

def slide_text(slide):
    out = []
    for sh in slide.shapes:
        if sh.has_text_frame:
            t = sh.text_frame.text.strip()
            if t:
                out.append(t)
    return "\n".join(out)

prs = Presentation("deck.pptx")
for i, slide in enumerate(prs.slides, 1):
    print(f"\n===== 第 {i:02d} 页 =====")
    print(slide_text(slide))
```

### 3.2 与讲话稿比对

```python
import re
from docx import Document
from pptx import Presentation

def norm(s):
    # 去掉空白和标点，只比字
    return re.sub(r"[\s，。、；：“”‘’（）《》！？—…·,.;:()\[\]\"']", "", s)

src = norm("\n".join(p.text for p in Document("讲话稿.docx").paragraphs))
prs = Presentation("deck.pptx")
missing = []
for i, slide in enumerate(prs.slides, 1):
    for sh in slide.shapes:
        if not sh.has_text_frame:
            continue
        for line in sh.text_frame.text.splitlines():
            line = line.strip()
            if len(line) >= 6 and norm(line) not in src:
                missing.append((i, line))

print("未在原稿找到的上屏文字：", len(missing))
for i, line in missing:
    print(f"  p{i:02d}: {line}")
```

**处理原则**：`missing` 里的条目逐条判断——是原句截取（可保留）、版式序号（可保留）、还是自己造的词（必须删）。不要直接把比对结果当“错误”，要人工判断。

### 3.3 重复数字扫描

```python
import re
from collections import defaultdict
from pptx import Presentation

hits = defaultdict(list)
for i, slide in enumerate(Presentation("deck.pptx").slides, 1):
    for sh in slide.shapes:
        if sh.has_text_frame:
            for m in re.findall(r"\+\d+(?:\.\d+)?%|\d+(?:\.\d+)?%|\d+\s*倍", sh.text_frame.text):
                hits[m].append(i)

for num, pages in hits.items():
    if len(pages) > 1:
        print(num, "出现在页", pages, "→ 只保留一个视觉重点")
```

## 四、文本溢出估算

没有渲染器时，用“字宽 × 行数”粗算，超过文本框高度就缩字号或删字：

```python
import math

def est_height_in(text, box_w_in, font_pt, line_spacing=1.3):
    # 中文按 1em 估；英文数字按 0.6em 估
    em_w = font_pt / 72.0
    per_line = max(1, int(box_w_in / em_w))
    lines = 0
    for para in text.split("\n"):
        chars = sum(0.6 if ord(c) < 128 else 1.0 for c in para)
        lines += max(1, math.ceil(chars / per_line))
    return lines * em_w * line_spacing
```

**经验值**：13.333 英寸宽、左右边距 0.8 后，10.5pt 中文一行约 55–60 字；12pt 约 48–52 字；结论句 30pt 一行约 20–22 字。超过三行就拆页或删字。

## 五、版本与 diff

- 每轮新建 `_vNN`，不覆盖上一版；A/B 方案用 `vNNA` / `vNNB`。
- 只改指定页时，用 python-pptx 打开旧版 → 改目标页 → 另存新版，并在交付说明写“只动第 X 页”。
- 用户说“封面保留”后，封面加入锁定清单；后续 diff 应显示 0 处封面变化。
- 定稿用日期命名（如 `-新-1102`）；过程稿保留 `vNN`，便于回退。

## 八、常见失败模式

| 失败模式 | 早期信号 | 预防 |
|---|---|---|
| 结构做错 | 目录和讲稿对不上、章节页比讲稿多 | 第 2 步先确认“几个部分” |
| 文字太多 | 每页超过 350 字、结论句缺失 | 第 3 步大纲就写结论句 |
| 版式单调 | 连续 3 页同版式、缩略图全是方块 | 第 5 步做版式节奏表 |
| 数字重复 | 同一数字在 2 页以上放大 | 交付前跑重复数字扫描 |
| 视频错位 | 标题和画面内容对不上 | 先看视频再定页 |
| 暗页/灰字 | 投影后看不清 | 过渡页用浅底；灰字加深 |
| 字体跑版 | Mac 预览正常、会场异常 | 统一字体 + 提示风险 + 会场试播 |
| 改坏已确认页 | 用户说“怎么封面变了” | 锁定清单 + 只改指定页 |

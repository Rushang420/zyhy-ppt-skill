## 一、深蓝体系（路线 A）

### 1.1 色板

```python
NAVY    = #0B2B4E    # 深海军蓝：封面/章节底、主标题
BLUE    = #005DA2    # 主蓝：主色块、重点数字、章节序号
BLUE2   = #2E86C8    # 亮蓝：次级强调、图形
SKY     = #6FB7E8    # 浅蓝：辅助图形、渐变
PALE    = #F2F8FD    # 极浅蓝：大面积浅底
LIGHT   = #E6F2FA    # 浅蓝底：信息区/浅色版块
GOLD    = #FFC000    # 点睛金：细线、序号、关键字（≤5%）
RED     = #C00000    # 提示红：极少量，不整体转红
GRAY    = #5B6B7A    # 正文灰
MIDGRAY = #8A9BAA    # 页脚灰（浅底上偏淡，必要时加深）
WHITE   = #FFFFFF
```

**配色比例**：蓝 60–70% / 白 20–30% / 金 ≤5% / 红 ≤3%。金色只做“线”和“点”，不做大面积底。

### 1.2 字体与字号

| 用途 | 字体 | 字号 |
|---|---|---|
| 封面主标题 | 微软雅黑 Bold（书法效果可换华文行楷） | 36–44pt |
| 内页标题 | 微软雅黑 Bold | 26–32pt |
| 结论句/金句 | 微软雅黑 Bold | 24–30pt |
| 数字 | Arial / 微软雅黑 Bold | 48–80pt |
| 正文 | 微软雅黑 | 12–16pt |
| 说明/注释 | 微软雅黑 | 9–11pt |
| 页脚 | 微软雅黑 | 8–9pt |

**华文行楷只作封面/结尾点睛**，且必须提示：Mac 预览常缺该字体，会回退；Windows 会场电脑才看得到书法效果。

### 1.3 版式原型

**封面**

- 全幅海港/船舶图 + NAVY 遮罩；或 NAVY 纯底 + 右侧大图。
- 标题两行以内，主标题 40pt 左右；副标题 16–18pt；金色细线分隔；时间/会议名小字。
- logo：左上角，彩色版约 1.05×0.67 英寸；深色底用白色反白版。
- 不堆装饰：一条金线 + 一张图 + 两组字即可。

**开篇之问**

- 用“背景判断/设问”开场，不用 01/02/03 编号（否则像第二个目录）。
- 左文右图或全幅图压字；标题句不超过两行；底部一句设问用 深蓝体系或金色强调。

**目录**

- 只出现一次。左侧大数字 01/02 + 右侧整幅图；或左侧竖排两部分 + 右侧图。
- 条目按“部分”列，不按子点列；每个条目一行，不加卡片框。

**章节扉页（过渡页）**

- **浅雾蓝底**（LIGHT/PALE），不用近黑色船体底（真实反馈：过渡页太暗）。
- 大数字 01/02 用 深蓝体系；标题深蓝；副标题中蓝/灰；logo 彩色版。
- 与内容页保持同一明度体系；章节页不是“熄灯页”。

**内容页（三种常用）**

1. **大数字 + 清单**：左侧 2–4 个大数字纵向排列，右侧整幅照片/金句；数字用 BLUE，说明用 GRAY。
2. **全幅图 + 压字**：图占 60–70%，文字压在深色区域；不要给图加边框。
3. **阶梯横幅/时间线**：三段错落、深浅节奏；不用三张等宽卡片。

**视频页**

- 深色/浅色整底均可，但视频框要大：宽 ≥8 英寸，16:9。
- 标题 24–28pt + 一句说明 11–12pt；视频下方一行“时长/内容”小字。
- 单独成页，不和三条文字挤在一页。

**结尾**

- 深蓝底 + 一句话 + 企业 IP/IP 收尾；或全幅海港图压暗。
- 企业 IP不要单独贴：与旗/港口/集装箱合成，或站在画面右下角带落地阴影。

### 1.4 logo 与 IP 规则

| 元素 | 位置 | 尺寸 | 备注 |
|---|---|---|---|
| logo 彩色 | 封面左上 | 1.0–1.05 英寸宽 | 浅底用彩色 |
| logo 白色 | 深色封面/章节/结尾 | 0.98–1.0 英寸宽 | 深底反白 |
| logo 内页 | 右上角 | 0.9 英寸宽 | 每页同一位置 |
| 企业 IP | 结尾右下 / 与场景合成 | 1.6–2.8 英寸高 | 不做孤立头像徽章 |
| 企业 IP + 红旗 | 党建融合页右侧 | 3.3×4.4 英寸 | 合成图，不是贴纸 |

## 二、党建朱墨体系（路线 B）

### 2.1 色板

```python
PAPER   = #F6F2EA    # 纸白：内容页底色（不是纯白）
PAPER2  = #EFE8DB    # 浅纸：极少量信息底
RED     = #A32B2B    # 朱红：标题带、编号、强调
RED_DK  = #7E1F1F    # 深朱：封面/尾页/收口通栏
GOLD    = #A98A4B    # 暗金：细线、序号
INK     = #1E1E1E    # 墨黑：标题、结论
INK2    = #4A4741    # 墨灰：正文
GREY    = #8A8378    # 注释灰（浅底上偏淡，慎用）
LINE    = #D8D0C0    # 细线
WHITE   = #FFFFFF
FADE    = #E9E0CF    # 右上角淡号
```

> 早期还有一个“报告风”变体：`RED #A61C1C`、`GOLD #C8A45A`、`PAPER #FBF9F5`、`INK #1A1A1A`。最终交付采用上面的朱墨值；不要混用两套。

**配色比例**：纸白 70–80% / 朱红 10–15% / 墨 5–10% / 暗金 ≤3%。红色只出现在标题带、编号、结论句、金句条，不铺满内容页。

### 2.2 字体与字号

| 用途 | 字体 | 字号 |
|---|---|---|
| 封面标题 | 宋体 Bold | 40–46pt |
| 尾页主句 | 宋体 Bold | 34–40pt |
| 每页结论句 | 宋体 Bold | 28–34pt |
| 栏头 | 宋体 Bold | 12–13pt |
| 正文 | 微软雅黑 | 10–12pt |
| 引文/金句 | 楷体 | 10–12.5pt |
| 序号/注释 | 微软雅黑 / 宋体 | 8.5–10pt |

### 2.3 版式函数（参考 `scripts/build_demo.py` 的骨架）

```python
# 页面框架：左侧细线 + 右上淡号 + 页标题 + 朱红短线
chrome(s, idx, kicker, title, tw=10.0)
# 页脚：细线 + 主题小字 + 右上页码
footer(s, n)
# 红标题带：整宽红带 + 金线 + kicker/标题/副标题 + 大号章节数字
band(s, num, kicker, title, sub="")
# 小标签：浅纸底 + 细线 + 居中字（仅少量使用）
chip(s, x, y, w, h, t, sz=9.5, ...)
```

**内容页的默认骨架**

1. 左上 kicker（9pt 朱红，写“第三部分 · 总论”）。
2. 一句 28–34pt 宋体结论句（占 1–2 行）。
3. 一条 0.9 英寸朱红短金线（`goldline`）。
4. 下方 2–3 栏内容：编号 + 关键词 + 细横线；栏间竖细线。
5. 页脚细线 + 主题小字 + 页码。

**列内容不要做成块**：用 `01 / 02 / 03` 小号朱红序号 + 细横线分行；不要给每条加底色。

### 2.4 页面原型

| 原型 | 结构 | 适用 |
|---|---|---|
| 封面 | 深朱渐变 `#8C1513→#B2211E`，宋体白字两行，细金线，天安门/红旗丝带剪影 | 全书第 1 页 |
| 目录 | 五条竖排序号 + 朱红细线 | 五部分结构 |
| 红标题带 | 顶部 1.98 英寸红带 + 金线，白色 31pt 标题，右侧大号 01–05 | 每部分首页（3–5 页） |
| 结论页 | 一句大字 + 细线 + 2–3 栏关键词 | 大部分内容页 |
| 数字页 | 巨号时间/年份 + 3 项要素 | 全会概况、二十一大 |
| 对照页 | 左右双栏 + 栏头朱红短线 + 竖细线 | 两个确立、党建/党务 |
| 同心圆 | 三环 + 引线定义 | 党的工作/党的建设/党务工作 |
| 金句条 | 深朱通栏 + 白色宋体一句 | 每本 2–3 处，不每页都用 |
| 尾页 | 深朱底 + 原稿收口句 + 日期 | 最后一页 |

### 2.5 图片处理

- **只用公司自己的图**：船靠泊、岸桥、港区俯瞰、码头作业；来源优先往年公司 PPT/官方素材，不用外网图。
- **统一色调**：蓝色港口图 → 暗红/暖金单色（去饱和 + 红色叠加），再放到朱墨体系里，避免蓝红冲突。
- **裁切**：只取照片部分，去掉往年模板的边框/波浪图形。
- **压字**：深色遮罩（RED_DK + 70–80% 透明度）+ 白字；不要在原图上直接压黑字。
- **位置**：右侧竖幅、底部横带、整版底图三种；同一本里交替使用，形成节奏。

### 2.6 明确禁止

- 九宫格色块堆叠、四个描边胶囊、整页红底大色块。
- 模板感红旗/天安门/华表/白鸽满页贴；金色立体字；红色渐变按钮。
- 每页都放红标题带（只有部分首页用）。
- 把“中国元素”当内容：元素是标点，内容是文字和实景图。

## 三、“框加框”的替代版式

| 原版式 | 问题 | 替代 |
|---|---|---|
| 白底 + 圆角卡片 ×3 | 连续多页节奏平，像模板 | 左大数字清单 + 右整幅图 |
| 三张横条卡片 | 信息被切碎 | 阶梯式三条横幅，错落排布 |
| 九宫格色块 | 像 Excel，无重点 | 三栏纯文字 + 细横线 + 朱红序号 |
| 四个描边胶囊 | 像按钮，抢注意力 | 一行红字：两个确立 · 四个意识 · 四个自信 · 两个维护 |
| 每个信息点一个色块 | 视觉噪音 | 细线分隔 + 字号层级 + 留白 |
| 图片加圆角边框 | 像贴纸 | 全幅/大块面图，直接压字或留白 |

**判断标准**：把页面缩小到 30% 看，如果只剩一堆同样大小的方块，就是“框加框”。

## 四、投影与可读性

| 项目 | 要求 | 失败案例 |
|---|---|---|
| 对比度 | 浅底正文 ≥ `#4A4741`；深底正文纯白 | 灰字 `#8A9BAA` 投到浅底看不清 |
| 最小字号 | 正文 ≥10pt；注释 ≥8.5pt | 页脚/背景句 7pt，后排看不见 |
| 安全边距 | 四边 ≥0.6 英寸；页码不贴边 | 页脚文字被裁 |
| 16:9 | 13.333×7.5；图片按比例裁切 | 4:3 拉伸变形 |
| 视频 | 宽 ≥8 英寸；单独页；首帧无错字 | 视频挤在左半边 |
| 动画 | Morph 仅 PowerPoint 2019+/365；给降级说明 | GIF 逐帧卡顿 |

## 五、字体与跨平台

- 中文 run 必须同时写 `a:latin` / `a:ea` / `a:cs`；只设 `run.font.name` 在部分系统会回退成默认字体。
- Mac 上做的预览：宋体/华文行楷/微软雅黑可能被替换，**预览通过 ≠ 会场通过**；交付时明确提示“最终请在 Windows PowerPoint 再看一遍”。
- 需要绝对稳定时：标题用宋体/微软雅黑，正文用微软雅黑；书法字体只做封面主标题，且准备“无书法字体”的备用版式。

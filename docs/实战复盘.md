## 一、项目长什么样

| 项 | 内容 |
|---|---|
| 委托方 | 某央企二级单位的一个职能部门 |
| 场景 | 年度务虚会，两天，部门负责人发言 ≤15 分钟 |
| 任务 A | 部门年度工作汇报 + 下一年打算，深蓝体系，演讲版，含 2 段视频 |
| 任务 B | 分管领导学习传达上级重要会议精神，朱墨党建专题，20 页以内 |
| 周期 | 5 天（任务 A 4 天，任务 B 1 天） |
| 对话 | 2 个会话、47 轮、约 950 次工具调用 |
| 结果 | 任务 A 16→19 页；任务 B 43 页大纲→19 页报告版 |

两本册子的定位完全不同，这是整个项目最重要的一条分界线：

| | 任务 A：部门年终汇报 | 任务 B：领导学习传达 |
|---|---|---|
| 讲话人 | 部门负责人 | 分管领导 |
| 性质 | 部门年度工作 + 下一年打算 | 政治传达 + 结合企业实际部署 |
| 视觉 | 深蓝、海港实景、企业 IP | 朱墨、白底红带、中国元素 |
| 结构 | 两部分：认知升级 / 持续改进 | 五部分：概况 / 主要内容 / 决定 / 上级部署 / 近期重点 |
| 难点 | 把部门工作讲成“价值证明” | 意思和用字不能改，又不能整段上屏 |

## 二、五个阶段

### 阶段 1｜需求分析（第 1 天上午）

第一条消息给了三份材料（会议通知 + 两本往年参考稿），但没有说页数、时长、风格比例、交付格式。

第一轮没做图，只做了四件事：

1. 读通知，确认时间、地点、时长、听众、材料归口；
2. 读两本参考稿，拆出画幅、主色、结构、气质；
3. 找到同目录下的讲话稿，判断它才是内容底稿；
4. 先复述理解，再列 6 个待确认问题。

用户给的六条确认，成为后续所有版本的基线：主体、底稿、蓝色为主、16:9、演讲版、先出 PPTX。

**经验**：第一轮只问 6 个问题，不急着出图。猜错画幅/时长，全盘重做。

### 阶段 2｜视觉返工（第 1 天中午）

用户的反馈都指向“观看体验”：

1. 企业 IP 不要单独摆放，要融合进页面；
2. “整体都是框加框，很容易看着看着就无聊了”；
3. “第 2 页和第 3 页是两个目录么？”；
4. “同一个数字连续两页都是重点”。

对应的改法：

- 拆卡片墙，改全幅图/大数字/阶梯横幅/时间线；
- 开篇页去掉 01/02/03 编号，改陈述式；
- 两页分工：一页讲结果、一页讲方法，同一数字全篇只做一次主视觉。

**经验**：每 3–4 页检查一次版式重复；“框加框”是默认陷阱，不是用户挑剔。

### 阶段 3｜结构三次纠正（第 1 天下午）

这是全项目最关键的转折。用户连续三次纠正：

| 轮次 | 用户原话 | 实际含义 |
|---|---|---|
| 1 | “应该是按照：第一部分……第二部分……三、……” | 先按讲话稿的三段式排 |
| 2 | “严格按照文稿的内容来……其中我们的亮点是宣传部分” | 不要自加成绩单/问题诊断/目标表 |
| 3 | “其实严格意义上讲这个是两部分” | 第三个点是第二部分的子点，不是第三部分 |

最终结构：两部分，第二部分下含宣传、党建、数智三个点，宣传连续 4 页。

**经验**：画第一页前，必须用一句话确认“这本册子分几部分、每部分下面有几点”。结构错一次，后面所有页码、章节页、视频位都要重排。

### 阶段 4｜内容、视频与拆分（第 2 天）

- 用户自己重做封面，明确“保留这个封面不要动”；
- 新版讲话稿逐条审阅，同步 12 处表述；
- AI 视频原想放“数智”后面，核对画面后发现讲的是宣传成果，建议放回宣传段；
- 视频开头闪了旧数字，裁掉前 1.2 秒；
- 党建部分从 1 页拆成“1 页介绍 + 3 页分述”，数智后再加视频页；
- 视频位置做 A/B 两版（内嵌 vs 单独一页），用户选单独一页，标题改片名式。

**经验**：视频不是装饰，先核对它讲的是哪一部分，再决定放哪；涉及加页/不加页，直接做两版比争论快。

### 阶段 5｜细节与另一条线（第 3–5 天）

- 只改第 2 页：公司更名信息补全，做三版让用户选；
- 用户指出“公司改名是重点，字为什么比下属单位的小”，层级反转：公司新名 30pt > 下属单位 22pt > 小标题 20pt；
- 灰色字太淡，统一加深；
- 网页结尾 POC 被否（GIF “一顿一顿”），改 PowerPoint Morph：两页同对象位移，6 秒平滑过渡；
- 第二条线从 43 页大纲压到 20 页，再做 19 页报告版；
- 用户三次说“文字太多/块块太多”，最终改成“每页一句结论 + 关键词 + 公司实景图”。

**经验**：用户说“感觉不对”时，先判断是结构、信息过载、视觉疲劳还是事实错误，四类改法完全不同。

## 三、10 条关键决策

| # | 决策 | 为什么 |
|---|---|---|
| 1 | 先分析需求，不直接做封面 | 15 分钟/20 页/画幅都是硬约束 |
| 2 | 视觉 80% 参考往年首选稿，叙事借第二本 | 保住“经营感”，不变成党建理论课 |
| 3 | 不自加“成绩单/问题诊断/目标表” | 讲话稿没有的章节，不替领导创造 |
| 4 | 第三个点归入第二部分 | 章节页从 3 个减为 2 个 |
| 5 | 同一数字全篇只做一次重点 | 连续两页重复会拖节奏 |
| 6 | 企业 IP 融合进画面 | 不做“贴纸式 IP” |
| 7 | 视频先核对内容归属 | 画面内容和章节标题必须一致 |
| 8 | 视频页做 A/B 两版 | 结构选择让用户选，比争论快 |
| 9 | 网页动效改 PPT Morph | GIF 帧率不可控；Morph 是原生连续运动 |
| 10 | 党建专题从“全文上屏”改“骨架+一句结论” | 20 页装不下 6000 字，必须取舍 |

## 四、12 条反馈 → 改法

| 用户原话 | 真实问题 | 正确改法 |
|---|---|---|
| “框加框，看着无聊” | 版式语言单一 | 拆卡片，改全幅图/左右分栏/阶梯/时间线 |
| “两个目录么？” | 开篇页用了目录语法 | 去编号，改陈述句 |
| “同一数字连续两页” | 重点重复 | 一页结果、一页方法 |
| “其实是两部分” | 章节层级错 | 减章节页，子点归入第二部分 |
| “文字太多” | 没有结论句 | 加一句结论，删阐述，关键词化 |
| “块块太多” | 用色块代替秩序 | 去色块，改细线/留白/字号 |
| “过渡页太暗” | 大面积深色投影发脏 | 深底改浅雾蓝，logo 改彩色 |
| “视频内容不是这一段” | 素材归属错 | 先核对画面，再决定放哪 |
| “GIF 一顿一顿” | 帧率/格式不对 | 改 PPT Morph 或嵌入视频 |
| “灰字太淡” | 对比度不足 | 灰字加深一到两级 |
| “公司改名重点，字反而小” | 信息层级反了 | 公司名 30pt > 下属单位 22pt > 小标题 20pt |
| “太模板化” | 只有版式没有气质 | 减字、上中国元素、做报告结构 |

## 五、7 条可以带走的经验

1. **先锁结构，再动版式。** 结构返工 3 次，成本远高于先做 3 页样张。
2. **讲话稿是骨架，不是全文。** 每页一句结论；意思和用字不改，但不必整段上屏。
3. **每页换一种版式语言。** 连续 3 页“白底 + 圆角框 + 三卡片”就警报。
4. **同一数字只做一次主视觉。** 第二次出现只能作背景小字。
5. **视频先看画面再排位置。** 不要按文件名/口述判断。
6. **公司自己的图 > 外找图。** 跨色系照片先做单色调统一。
7. **大文件从第一天分开管理。** 文本/代码/小成品进 Git，大素材单独存放。

## 六、下次开工的 6 个问题

1. 这本册子是谁讲、讲多久、给谁听？
2. 内容唯一依据是哪份讲话稿/通知？有没有上级口径？
3. 全篇分几部分？每部分下面几个点？有没有参考结构？
4. 视觉沿用哪套体系？有没有 logo、IP、实景图？
5. 要不要视频/动画？视频讲的是哪一段？
6. 什么时候要、先交 PPTX 还是 PDF、要不要演讲备注？

# 国企 PPT 制作 · DSH Skill

> 把领导讲话稿/会议材料，变成一本**结构对、文字少、有报告感、能投影**的中文 PPT。
> 这是一个 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）技能包，也可以当作普通的 PPT 工作流文档使用。

---

## 这个技能解决什么问题

国企/央企内部会议 PPT 的难点，通常不是“设计不够炫”，而是：

- 讲话稿 6000 字，会议要求 15 分钟、20 页以内，**不知道该删什么**；
- 结构改来改去：明明是两部分，被做成了三部分；子点被提成了章节；
- 每页都是“白底 + 圆角框 + 三个卡片”，领导看到第 8 页就开始走神；
- 想加中国元素，一加就变成“红块 + 天安门”模板；想减字，一减就只剩口号；
- 视频、Morph、字体、页码，最后一刻才发现会场播不了。

这个技能把上面这些问题拆成 **6 个必问 + 7 步流程 + 两套视觉规范 + 16 条真实反馈**，让 Agent 按顺序做，而不是一上来就画封面。

## 7 步流程（技能的核心）

| 步 | 动作 | 产出 | 硬标准 |
|---:|---|---|---|
| 1 | 读材料 | 通知、讲话稿、往年参考稿、公司素材 | 能复述会议背景/时长/听众 |
| 2 | 需求确认 | 6 问答案 + 5–8 行理解复述 | 用户回复“对/按这个来” |
| 3 | 结构大纲 | 页级大纲：页/页面/结论句/上屏文字/依据/版式 | 每页能指回原稿段落 |
| 4 | 视觉样张 | 封面 + 章节页 + 1–2 页内页 | 用户选定一版 |
| 5 | 全量铺页 | python-pptx 生成整本 PPTX | 页页有结论句，无“框加框” |
| 6 | 逐页审阅 | contact sheet + 逐字回查表 | 重复数字/错字/溢出清零 |
| 7 | 交付 | PPTX + PDF + 无视频版 + 说明 | 能打开、能播、字体风险已提示 |

**不要跳步。** 最常见的返工不是“不好看”，而是第 2 步结构没对齐、第 3 步大纲没给用户过。

## 两条主路线

### 路线 A：部门务虚会 / 年终汇报

- 气质：深蓝、海港、大画面、大数字、有记忆点；
- 结构：封面 → 开篇设问 → 目录 → 第一部分（认知/目标）→ 第二部分（方向/举措）→ 结尾；
- 规则：开篇页不是目录；子点不单独做章节；宣传是亮点就连续铺 4 页；同一数字只做一次主视觉；视频单独成页。

### 路线 B：领导学习传达 / 党建专题

- 气质：朱墨、纸白、红标题带、细线、大留白、报告感；
- 结构：封面 → 目录 → 五个部分 → 尾页；
- 规则：意思和用字不能改（可截取、可分句，不改写）；每页一句 28–34pt 结论；去色块，用线/留白/字号；中国元素只做点缀；尾页不自造“谢谢”。

## 两套视觉规范（摘要）

| | 深蓝体系（路线 A） | 朱墨体系（路线 B） |
|---|---|---|
| 底色 | 深海军蓝 / 浅蓝 | 纸白 `#F6F2EA` |
| 主色 | `#0B2B4E` / `#005DA2` | 朱红 `#A32B2B` |
| 点睛 | 金 `#FFC000`，面积 ≤5% | 暗金 `#A98A4B`，面积 ≤3% |
| 标题 | 微软雅黑，36–44pt | 宋体，40–46pt |
| 正文字号 | 12–16pt | 10–12pt |
| 版式 | 全幅图压字 / 大数字 / 阶梯横幅 / 时间线 | 红标题带 + 细金线 + 编号细线 |
| 禁止 | 连续多页圆角卡片、默认阴影 | 九宫格色块、描边胶囊、满页天安门 |

完整色值、字号、logo/IP 位置、图片处理见 [`references/02-视觉规范.md`](skills/guoqi-ppt/references/02-视觉规范.md)。

## 四页脚手架 Demo

```bash
cd skills/guoqi-ppt
bash scripts/run_demo.sh
# 输出 scripts/demo.pptx：4 页、16:9、封面/内容页深蓝，章节/尾页朱墨
```

`build_demo.py` 包含可复用的：

- 16:9 画布与安全边距；
- 中文字体（`a:ea`）设置，避免中文回退；
- 动态页码（`len(prs.slides)`）；
- 大数字、故事矩阵、章节红带、尾页；
- 可选 mp4 嵌入（`--video path.mp4`）。

依赖：Python 3.10+、`python-pptx`；PDF/PNG 预览建议装 LibreOffice。

## 五条底层原则

1. **保真优先。** 不新增观点、数据、事例；核心提法一字不改；拿不准就回原稿或问用户。
2. **结构先行。** 先确认“几部分、每部分几个点”，再动版式；结构错一次，页码/章节页/视频位全部重排。
3. **一句结论。** 每页必须有一句能被记住的话；没有结论的页面，合并或删掉。
4. **版式有节奏。** 每 3–4 页换一次版式家族；“白底 + 圆角框 + 三卡片”是默认陷阱。
5. **交付可验证。** PPTX + PDF + 无视频版；视频首帧/关键数字核对；字体和 Morph 版本风险提前说明。
